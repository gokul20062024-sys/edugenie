# EduGenie

EduGenie is an AI-powered learning assistant built with Flask and Gemini AI.

## Features

* Ask questions and get AI-powered answers
* Generate topic explanations
* Generate quizzes
* Create learning paths
* Generate study summaries

## Technologies Used

* Python
* Flask
* Google Gemini AI
* HTML
* CSS
* JavaScript

## How to Run

1. Create and activate a Python virtual environment.
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Set your Gemini API key as an environment variable:

```text
GEMINI_API_KEY=your_api_key
```

4. Start the application:

```bash
python main.py
```

5. Open:

```text
http://127.0.0.1:5000
```

## Project

EduGenie is designed to help students learn topics using simple AI-generated explanations, quizzes, learning paths, and summaries.
